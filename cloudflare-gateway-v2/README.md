## Required end-to-end actions

Follow **[OAuth owner setup](oauth-auth-server/README.md)**. The following **cannot** be completed by an unauthenticated GitHub CI run:
1. Authorize/select your **Cloudflare account** (Free may suffice within request and KV limits).
2. Register a private GitHub OAuth App with correct callback.
3. Create Cloudflare KV namespace and set credentials **privately** on the correct Workers (auth: GitHub client id/secret, owner numeric ID; resource: NVIDIA API key and owner ID). **Never commit credentials, send them in ChatGPT, or log them.**
4. Deploy **authorization Worker first, resource Worker second** using the OAuth-specific configuration files.
5. Verify remote OAuth discovery, PKCE, GitHub login and consent, protected `tools/list` for exactly three tools and a **real SYNTHETIC NVIDIA inference**, followed by review and evalset.
6. Create/rebind a custom MCP plugin at the new HTTPS `/mcp` endpoint (ChatGPT and Codex independently). Keep legacy Railway untouched until both clients are verified.
